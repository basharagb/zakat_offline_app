# مؤوياتي — حاسبة زكاة دون إنترنت

تطبيق Flutter مستقل عن مشروع النظارات الذكية. استُلهمت منه الهوية البصرية فقط: خلفية كحلية داكنة، بطاقات داكنة، لمسات خضراء، وواجهة عربية من اليمين إلى اليسار.

## التشغيل

```sh
cd zakat_offline_app
flutter pub get
flutter run
```

## الوظائف

- كتابة مصدر المال مثل الراتب أو العمل الحر، وإدخال العملة يدويًا مثل الليرة السورية. تُستخدم عملة واحدة لجميع البنود في الحساب.
- إدخال مدة امتلاك المال بعد بلوغ النصاب من يوم إلى ١٠٠ سنة؛ تُحسب الزكاة عن كل حول قمري مكتمل. مدة تحصيل الراتب أو الدخل لا تُقسم عليها الزكاة.
- إدخال مبلغ واحد مملوك حاليًا، مع مصدر الدخل والنصاب المقوم بالعملة نفسها.
- إدخال قيمة النصاب يدويًا لأن سعر الذهب/النصاب يتغير ولا يجلب التطبيق أي أسعار من الإنترنت.
- احتساب ٢٫٥٪ عن كل حول قمري مكتمل بعد بلوغ النصاب، وفق البيانات المدخلة. عند امتداد المدة لسنوات متعددة يفترض التقدير ثبات صافي المبلغ وعدم سبق إخراج زكاته؛ السنوات الماضية قد تحتاج حسابًا منفصلًا.
- حفظ المدخلات محليًا على الجهاز باستخدام `shared_preferences`.
- لا توجد واجهة API أو خدمة خادم أو استدعاءات شبكة في التطبيق. إصدار Android الرئيسي لا يطلب صلاحية الإنترنت.

## البنية

```text
lib/
  app/                         الألوان والثيم
  features/zakat/
    domain/                    المدخلات، النتيجة، المستودع، وحالة الاستخدام
    data/                      التخزين المحلي وتنفيذ المستودع
    presentation/              واجهات Flutter ومتحكم GetX
```

## ملاحظة فقهية

الحاسبة تقدير عام وليست فتوى. تعتمد في النقد على بلوغ النصاب ومرور حول قمري وإخراج ربع العشر (٢٫٥٪). المدة المدخلة هي مدة امتلاك المال بعد بلوغ النصاب، وليست مدة كسبه. أدخل قيمة النصاب الحالية حسب معيار الجهة التي تتبعها. توجد تفاصيل واختلافات فقهية في ضم المال المستفاد أثناء الحول والديون والذهب المستعمل؛ استفتِ جهة موثوقة لحالتك.

مرجع عام للمقدار والنصاب: [دار الإفتاء المصرية — نصاب زكاة المال والمقدار الواجب فيها](https://www.dar-alifta.org/ar/Fatwa/Details/18349/%D9%86%D8%B5%D8%A7%D8%A8-%D8%B2%D9%83%D8%A7%D8%A9-%D8%A7%D9%84%D9%85%D8%A7%D9%84-%D9%88%D8%A7%D9%84%D9%85%D9%82%D8%AF%D8%A7%D8%B1-%D8%A7%D9%84%D9%88%D8%A7%D8%AC%D8%A8-%D9%81%D9%8A%D9%87%D8%A7)

ولتفصيل المال المستفاد أثناء الحول: [دائرة الإفتاء الأردنية — حكم المال المستفاد خلال الحول](https://www.aliftaa.jo/fatwa/2951/)
